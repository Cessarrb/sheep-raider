# Sheep Raider en el navegador

Página para jugar mi copia de *Looney Tunes: Sheep Raider* (PS1) en el navegador y en el celular, usando [EmulatorJS](https://emulatorjs.org) (core PCSX-ReARMed).

- El juego **no está en este repo**. Se carga desde el dispositivo con el botón de la página y no se sube a ningún lado.
- Formatos: `.chd` (recomendado para celular), `.cue`/`.bin`, `.zip`.
- Proyecto personal de prueba.
